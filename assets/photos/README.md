# Фотоархив MILANA — TWO YEARS

Положи сюда ровно 15 фотографий с такими именами:

| Файл | Роль в истории |
| --- | --- |
| `before-01.webp` | твоя фотография до отношений |
| `before-02.webp` | портрет Миланы до отношений |
| `beginning-01.webp` | самый важный кадр начала |
| `beginning-02.webp` | кадр первых недель 01 |
| `beginning-03.webp` | кадр первых недель 02 |
| `month-01.webp` | фото первого месяца 01 |
| `everyday-01.webp` | случайный момент 01 |
| `everyday-02.webp` | случайный момент 02 |
| `everyday-03.webp` | случайный момент 03 |
| `places-01.webp` | фотография важного места |
| `half-year-01.webp` | главный кадр полугода |
| `first-year-01.webp` | главный кадр первого года |
| `milana-01.webp` | лучший портрет Миланы |
| `finale-01.webp` | свежая совместная фотография |

## Требования

- Основной формат: WebP.
- Для исходников лучше хранить 2 версии: preview `~300–500 КБ` и крупную `~700–1200 КБ`.
- Не переименовывай файлы без изменения манифеста `src/data/story.js`.
- Если фотографии пока нет, сайт покажет аккуратный editorial placeholder без битой иконки и без layout shift.
- Один кадр может использоваться в нескольких главах: это намеренный монтажный приём, а не дубликаты загрузки.

После добавления файлов достаточно закоммитить папку — код уже подключает их лениво рядом с нужной сценой.
